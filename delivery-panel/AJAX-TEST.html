AJAX Profile Implementation Test

Test suite for AJAX functionality in rider profile page

Prerequisites

✓ Logged In: User must be logged in as a rider
✓ Browser Console: Open with F12 to see detailed request logs

Test Cases

1 Form Submission via AJAX:

Steps:

  1. Navigate to profile page
  2. Click "Edit" on Personal Information
  3. Change first name
  4. Click "Save Changes"
  5. Verify: Green notification appears, no page reload initially
  6. Page reloads after 1.5 seconds
2 AJAX Headers:

Steps:

  1. Open browser DevTools (F12)
  2. Go to Network tab
  3. Submit any profile form
  4. Verify: Request has "X-Requested-With: XMLHttpRequest" header
  5. Verify: Response has "Content-Type: application/json"
3 Password Change with AJAX:

Steps:

  1. Navigate to profile page
  2. Click "Change Password" in Security section
  3. Enter current password
  4. Enter new password (min 6 chars)
  5. Confirm password
  6. Click "Update Password"
  7. Verify: Success notification appears
  8. Verify: Form clears after submission
4 Client-side Validation:

Steps:

  1. Navigate to profile > Change Password
  2. Try to submit with mismatched passwords
  3. Verify: Error notification "New passwords do not match"
  4. Try with password less than 6 chars
  5. Verify: Error notification "Password must be at least 6 characters"
5 Server-side Validation:

Steps:

  1. Navigate to profile > Change Password
  2. Enter wrong current password
  3. Enter any new password (matching)
  4. Submit form
  5. Verify: Red error notification "Current password is incorrect"
6 Loading State:

Steps:

  1. Navigate to profile
  2. Click "Save Changes" on any section
  3. Verify: Button text changes to "Saving..." with spinner
  4. Verify: Button is disabled during submission
  5. Verify: Button returns to normal on completion
7 Multiple Section Updates:

Steps:

  1. Update Personal Information via AJAX
  2. Wait for success notification
  3. Update Address Information via AJAX
  4. Verify: Each section updates independently
  5. Verify: No conflicts or errors
8 Error Handling:

Steps:

  1. Open browser console
  2. Try to update profile
  3. Verify: Any errors display in red notification
  4. Verify: User can retry after error
9 Notification System:

Steps:

  1. Submit any profile form
  2. Verify: Green success notification appears top-right
  3. Verify: Contains "Success!" heading
  4. Verify: Has close (X) button
  5. Verify: Auto-dismisses after 5 seconds
10 JSON Response Format:

Steps:

  1. Open DevTools > Network tab
  2. Submit profile form
  3. Click on the profile POST request
  4. View Response tab
  5. Verify: JSON with "success": true and "message" field

Expected Behaviors

Scenario Expected Behavior
Valid update Green notification → Page reloads after 1.5s
Invalid data Red error notification → Form stays open for retry
Password mismatch Red notification "New passwords do not match"
Wrong current password Red notification "Current password is incorrect"
Empty required field HTML5 validation or red notification
Server error Red notification with error message

Browser Console Debugging

Enable Console Logging: Add the following to check request/response:

// In browser console:
const originalFetch = window.fetch;
window.fetch = function(...args) {
  console.log('AJAX Request:', args[0], args[1]);
  return originalFetch.apply(this, args)
    .then(r => {
      console.log('Response Status:', r.status);
      return r;
    });
};

Success Criteria

  • ✓ All form submissions work without page reload
  • ✓ AJAX headers are sent correctly
  • ✓ JSON responses are parsed correctly
  • ✓ Notifications appear and dismiss automatically
  • ✓ Loading states work during submission
  • ✓ Validation works both client and server-side
  • ✓ Password updates are secure (bcrypt verification)
  • ✓ Multiple form sections work independently
